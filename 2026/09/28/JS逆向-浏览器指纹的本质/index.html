JS逆向 - 浏览器指纹的本质

发表于2026-09-28|更新于2026-09-29|JS逆向
|浏览量:

本文主要认识和理解浏览器指纹

浏览器指纹

浏览器指纹是一组浏览器/设备环境的可观测特征（指纹信号）及其组合所形成的、具有一定区分能力的特征集合。

常见的指纹信号

设备信息

  1. navigator.userAgent ：最为典型的指纹信号，是浏览器的用户代理字符串。常常携带于在请求头中，该值与浏览器内核有关。
  2. navigator.appName : 现代浏览器永远为该’Netscape’。
  3. navigator.language ：首选语言，中文的话就是’zh-CN’。(曾被Anthropic利用，用来区分使用用户)
  4. navigator.productSub :当前浏览器的构建版本号。
  5. navigator.deviceMemory :设备内存的近似值。
  6. navigator.userAgentData.brands ：返回一个包含品牌信息的数组。
  7. navigator.userAgentData.getHighEntropyValues ：返回一个promise，它兑现为一个字典对象，其中包含低熵信息以及关于浏览器的请求的高熵信息。比如’[“architecture”（平台架构信息）,”model”（用户代理在移动设备上运行）,”platformVersion”（一个包含平台版本的字符串）,”fullVersionList”（一个具有 "brand" 和 "version" 属性的对象数组，分别表示浏览器名称和完整版本）]’。
  8. navigator.getBattery :提供了系统的电池信息，它返回一个包含电池对象的 promise 对象。
  9. screen ：获取屏幕分辨率信息
  10. devicePixelRatio ：物理像素与CSS像素比。

canvas指纹

canvas 2d

canvas 2d指纹是通过在浏览器创建一个canvas标签，接着调用getContext获取canvas2d对象，接着调用canvas2d的相关渲染API，接着调用canvas.toDataURL进行哈希
简单来说，canvas指纹反映的是“你的硬件+操作系统+浏览器+字体+驱动”在执行同一段绘画指令时产生的像素级差异。同一套操作在同一设备的浏览器短时间内不会变动，这个特性决定了指纹的区分度。

canvas webgl

canvas webgl指纹是通过在浏览器创建一个canvas标签，接着调用getContext获取webgl对象，接着调用getExtension启用webgl扩展，接着调用getParameter返回扩展信息
WebGL指纹是在浏览器使用WebGL时所展现出的硬件和软件配置信息，如显卡型号，驱动版本，操作系统等。

WebAudio指纹

生成相同的音频输入 → 经过浏览器/系统的音频处理链 → 获取输出结果 → 对结果做特征提取或哈希

同一设备在相同环境、相同浏览器、相同代码、相同音频参数下，Audio Fingerprint 通常应该稳定；但不能认为它永远不变,与运行环境有关。

插件和扩展指纹

navigator.plugins : 通过调用该api来检测浏览器的插件信息，区分度很高，每个人的浏览器安装组合因人而异，排列组合和版本都会对该指纹产生影响。
在实际网站采集指纹信号中，经常性会把PluginArray/Plugin/MimeType这三类结合起来，这三层互相指向

网页信息指纹

  1. location ：返回包含有关文档当前位置的信息
  2. document.currentScript ：返回当前正在处理其脚本。当在js代码里运行会直接返回运行的script元素，手动在控制台敲返回undefined。
  3. getComputedStyle：通过传入真实网址的节点返回对应的所有 CSS 属性的值

浏览器运行环境指纹（通常会以数字 布尔值 位掩码的形式）

  1. document.all : 它是一个真实存在的对象，但会“假装自己是 undefined”。
  2. dom操作：通过创建标签接着appendchild读取相关信息是否合理来验证dom操作能力。
  3. matchMedia：返回指定的媒体查询字符串解析后的结果。而在node需要手动实现。
  4. 浏览器与node的差异 ：调用浏览器特有的函数或进行toString验证是否为native方法 ；调用node特有的函数；原型链完整性；
  5. 调用object方法： 通过调用object方法查看描述符是否和浏览器环境保持一致。

指纹生成链路

浏览器环境信息->产生各种可观测特征->这些特征 = 指纹信号->每个信号有不同的区分度->多个信号组合->浏览器指纹
